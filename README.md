## 📖 Executive Summary
Conventional anti-fraud systems evaluate transactions in isolation, leaving institutions blind to coordinated fraud rings operating across linked accounts, shared device fingerprints, and synthetic identity networks. 

This platform implements an **Autonomous 5-Agent Pipeline** that connects relational signals into a unified multi-attribute graph, pinpoints high-risk fraud rings, and equips human analysts with explainable forensic dossiers and containment actions.

---

## 🤖 5-Agent Detection Pipeline (Slide 05 Architecture)

1. **Agent 1: Data Input Agent (`server/agents/dataInputAgent.js`)**  
   Ingests multi-channel transaction streams, account profiles, hardware device fingerprints, and proxy/network indicators into normalized graph nodes.

2. **Agent 2: Analysis Agent (`server/agents/analysisAgent.js`)**  
   Uncovers transaction behavioral anomalies including velocity spikes, nocturnal hops, pass-through ratios, and layering thresholds.

3. **Agent 3: Entity Linking Agent (`server/agents/entityLinkerAgent.js`)**  
   Performs multi-hop graph traversals across `Account <-> Device <-> IP <-> KYC/Tax ID` to discover device farming clusters and synthetic identity collisions.

4. **Agent 4: Risk Scoring & Explainability Agent (`server/agents/riskScorerAgent.js`)**  
   Executes cycle detection algorithms, computes composite threat scores (0–100), and drafts human-readable Explainable AI forensic briefs.

5. **Agent 5: Alert & Analyst Review Agent (`server/agents/alertAgent.js`)**  
   Prioritizes emergency containment alerts and powers human-in-the-loop actions (Freeze Ring, Flag for Law Enforcement, Add Case Notes).

## ⚡ Quick Start (Run on Laptop)

### Method 1: One-Click Launch (Windows)
Double-click the **`start.bat`** file inside this folder.  
It will automatically install packages, boot the server, and open your browser to `http://localhost:5000`.

### Method 2: Command Line
```bash
# 1. Install dependencies
npm install

# 2. Start server
npm start
```

Now open your web browser and visit:  
👉 **`http://localhost:5000`**
